# Customer Exception Agent 使用说明

这份原型对应报告中的 EXC-01 航班中断恢复与 EXC-02 投诉调查。
数据、其他 Agent 和审核组件均为模拟；程序会实际执行检查并保存处理记录。

## 打开演示

在项目文件夹中双击 `Start Exception Demo.command`，然后在浏览器打开：

http://127.0.0.1:8766/#exception-panel

如果提示端口已被占用，先打开上面的网页，可能已有一个演示程序正在运行。
关闭终端会停止网页服务；重新启动后，历史记录仍在。
启动脚本使用本机已安装的 `.venv` 环境；组员首次安装请看同目录的英文 README。

## 推荐演示顺序

1. 选择“正常案例”，点击“航班取消处理”。
   程序评估两份模拟替代方案：早到方案符合条件，总费用 AUD 680；
   另一份因时间不符合要求被排除。费用包含已付不可退的 AUD 180，
   不会假定原票款能退。原行程不被改写。
2. 点击“延误投诉处理”。
   程序根据计划到达与实际服务记录确认 90 分钟延误，并按照演示政策
   建议说明事实及表达歉意，不自行决定退款、赔偿资格或金额。
3. 选择“证据互相矛盾”，再点击任一按钮。
   结果应为“需要人工处理”，可在完整记录中查看冲突原因和证据。
4. 选择“涉及待人工审批的事项”。
   结果为“等待人工审批”。程序只保存审批申请，不会假装人工已批准。
5. 展开“已保存的处理记录”，点击旧记录。刷新页面后也可回看。

页面中的“建议已通过模拟检查”表示内部建议完成并保存，不代表已联系旅客、
已改订或投诉已结案。结果始终交给 Operations 协调后续处理。
