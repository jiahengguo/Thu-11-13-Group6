## 判定规则

- `PASS`：对应验收点已经在页面上观察到预期结果，不代表整项功能全部完成。
- `PARTIAL`：只完成前置步骤或中间状态，不能算完整闭环通过。
- `NOT_RUN`：未通过浏览器执行或核对；自动化覆盖不改变这个判定。
- `ISSUE_OBSERVED`：确实观察到失败、超时或冲突，另记恢复情况，不隐去失败。

真实云端接口脚本、真实浏览器操作和隔离自动化分别记录。真实服务连接不意味着库存、历史行程、政策或交易是真实业务数据。前置模拟数据准备不是页面验收，模型只在实际调用的步骤获得覆盖。

每轮记录代码提交、日期及时区、环境、角色、步骤、预期、实际、证据和未覆盖范围。截图只保留必要的模拟业务信息，不能包含密码、密钥、认证令牌或私密 manifest。历史证据不自动追溯到更新后的 main。
