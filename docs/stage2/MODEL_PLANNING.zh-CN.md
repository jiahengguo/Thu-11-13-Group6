# 默认门户的课程模型规划接线

对应 WN5620-54 的接线部分，复用既有 ModelPlanningEngine、CampusClient、Supplier 查询、PlanningValidator、共享 Reviewer 和私有 Planning 存储。启动脚本现在明确启用模型规划；直接启动服务器时可使用：

```sh
.venv/bin/python -m tripmate.portal.server --demo-pricing --model-planning
```

模型只收到已确认的旅行需求、当前合格报价的售价和行程属性，提出报价 ID 组合。客户账号、邮箱、密码和供应商成本不发给规划模型。确定性工具计算总价并检查完整项目、预算、时间、库存和其他约束；无效组合最多反馈修复三轮。有效结果才交共享 Reviewer 和 Operations 外发审核，模型不能决定批准或采用。

每次规划创建独立客户端/规划器，避免将上一次案件的尝试记录复用于下一案件；每次调用 25 秒超时、最多 2048 completion tokens，提示模型生成一至两套完整候选，将价格计算、校验和排名留给确定性工具。模型不可用、输出截断、虚构 ID 或持续无效时失败，不默默回退离线候选，也不把模型找不到方案解释成所有库存都不可行。配置缺失会阻止模型模式启动。

`start_demo.py --skip-model-probe` 仍启用上述真实模型路径，只跳过启动前探测；请求模型失败仍明确失败。直接服务器不带 `--model-planning` 则继续使用原确定性规划器，供明确的非模型调试使用，不得将这种结果表述为课程模型生成。

该选择依据 Stage 1 的 Agent 提案、工具校验和人工监督分工：复用已存在的有界循环，避免再引入框架或另建未集成聊天界面。供应数据准备仍采用结构化模拟事实，不需要模型替脚本编造供应商数据。

四项新增测试通过：模型组合经过实际门户业务服务校验并保存、隐私数据不进入模型输入、连接失败不回退、虚构报价有限修复后失败、缺配置阻止启动。模型传输是明确标记的测试替身；真实课程接口在 2026-10-27 05:00 续作中实际探测仍返回 `TOOL_UNAVAILABLE`。真实模型演示验收仍需课程服务/网络连通后执行，不能标为已完成。

最终完整回归：277 项全部通过，169.250 秒；包括既有认证、Supplier、Planning、Exception、审核、数据准备和必要失败场景。启动脚本/服务器帮助入口及 diff 检查通过。未制作 ZIP 或执行解压部署测试。

## 连接 VPN 后的真实验证（2026-10-27）

用户连接 USYD VPN 后，课程服务器 TCP 已连通，真实共享 Agent 的 JSON 提取通过 schema 校验。原 1024-token 规划请求把全部预算用于推理并截断；只提高至 4096 的实验又遇到代理 HTTP 502。代理拒绝 Qwen 扩展 `chat_template_kwargs`（422），本修复不添加该参数，也不依赖未生效的 `/no_think` 提示。

保持手册的标准请求字段，将提示收敛为一至两套候选、工具负责计算/排名，并为规划提供 2048-token 上限。真实模型实验一次调用约 5.71 秒，产生两套完整模拟行程，总价 AUD 539 和 AUD 660，所有现有确定性检查通过；实际用量为 492 completion tokens（其中 436 reasoning tokens），正常结束。输入来自明确的离线模拟需求/报价，在固定模拟时钟下校验，没有创建真实云案件或执行交易；此结果不代表真实门户、供应商和云数据的整体演示验收。

最终将已成功实验的提示顺序写入实际代码，客户端上限设为 25 秒。实际代码再次真实调用通过，约 6.90 秒，得到 AUD 429 / AUD 660 两套完整模拟方案，全部校验通过，使用 622 completion tokens（其中 545 reasoning tokens）。此前一次 20 秒复核曾超时，故仍保留超时/截断失败边界，不保证提供方延迟。修复后 12 项 campus 测试、4 项模型门户测试和 7 项 readiness 测试通过；此前 277 项完整回归是前置分支的基线，本次没有重新声称完整回归已执行。

用户随后明确目标项目并更新本地忽略的凭据，云端 Auth、私有 RPC 和 JWKS 检查通过，cloud/model 联合 doctor 返回 ready=true；此前 DNS/目标选择阻塞已解除。演示账户准备函数仍返回 HTTP 404 / PGRST202，完整云端业务未验收。见 [PR 验证审计](PR_VALIDATION_AUDIT_2026-10-27.zh-CN.md)。
